# Emission_Dashboard_from_databricks
An interactive data visualization dashboard powered by Databricks, designed to track, analyze, and monitor environmental emission metrics, resource consumption, and related expenditures across regions.

Interactive map and donut charts tracking regional emission distributions, highlighting top-emitting states (such as TX, AZ, IL, and FL).   
Emissions vs. Population Analysis: Scatter plot analysis comparing per capita emissions against population scales across top countries.   Consumption & Expenditure Tracking: Tabular breakdown tracking top regions by consumption volumes and associated financial expenditures.
